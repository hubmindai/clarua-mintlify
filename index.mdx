## What is Clarua?

Clarua is an AI coding partner that builds real applications from natural language. Describe what you want, drop in a spreadsheet, upload a design, paste an API spec, or point at a URL, and Clarua generates a working app you can edit, publish, and operate. Clarua is an AI coding partner that turns a prompt, a spreadsheet, a design, a screenshot, or an API spec into a working app. From there, it helps you edit, publish, and monitor what you built. This documentation covers what Clarua can do and how to use each feature.

You stay in control the entire time. Every change is a checkpoint, every environment is isolated, and every action the agent takes is visible and reversible.
