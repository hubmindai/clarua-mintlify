## Aug 16

**App · Install Clarua from the account menu.** Signed-in users can now install Clarua as a Progressive Web App from the account menu, next to **Get help**. The **Install app** row only appears when your browser has offered a native install prompt this session, you're not already running Clarua as an installed app, and you haven't dismissed the prompt in the last 90 days. Selecting it hands off to the browser's native install flow.

**App · English menu label reads "Gift Clarua".** The account menu's gift entry now reads **Gift Clarua** in English, matching every other localized catalog.

## Aug 12

**Build · Private registry is now Managed registry.** The npm registry that Clarua hosts for your workspace is now called [Managed registry](https://docs.lovable.dev/features/managed-registry), to set it apart from an external registry that you run yourself and connect through a build secret. Find it in Settings → Build & deploy → Managed registry. Nothing about how it works changed. The managed registry is available on Enterprise plans.
