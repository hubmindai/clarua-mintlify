## May 27

**Build · Point at a URL, get a clean codebase.** Give the agent the address of a site and get back a tidy, structured codebase that recreates it — not a tangle of scraped markup. It's a starting point you can actually build on, organized the way you'd write it yourself.

**Workspace · Social login for the apps you ship.** Add sign-in to a generated app without wiring up auth by hand — let your users log in with accounts they already have. It's configured from the dashboard and carried into the app you publish, so real authentication is a setting, not a project.

**Maker · Describe a part, get a printable 3D model.** Describe what you want in plain language and get back a real, watertight 3D model tuned to your printer — no CAD. The model is parametric, so you can change a dimension and regenerate, a confidence ledger flags anything it's unsure about, and you can export a ready-to-print file. Reach it with /maker or the 3D Maker studio.

## May 24

**Workspace · Self-serve restore from a daily backup.** Your projects are backed up daily, and rolling one back is something you can do yourself — pick a day and restore, no support ticket. It's there for the moment a change went wrong and you just want yesterday's version back.

## May 21

**Security · Security Scan — catch vulnerabilities before you publish.** One click scans your app for exposed secrets, injection sinks, missing row-level security, insecure requests, and risky configuration — with a weighted security score and a publish gate that can hard-block on criticals. It runs entirely on-device: your code never leaves the edge, and any secret it finds is masked before it's ever shown or stored. Each finding comes with a concrete fix and an ignore-with-reason audit trail.

**Analytics · App Analytics — usage insights for the apps you ship.** See how people actually use the apps you build: page views, custom events, conversions, and funnels in one dashboard. Privacy-first — no cookies, no third-party trackers; visitor identity is hashed at the edge and IPs are redacted. Drop in two lines and events start flowing.

**Skills · Skills — reusable instructions the agent remembers.** Teach the agent how you like things done once, then let it apply that playbook whenever a task matches — or trigger it yourself with a /command. Write a skill in the dashboard, import one as markdown, or save one straight from a chat. Only names and descriptions load up front, so a big library never slows the agent down.

**Workspace · Cross-project referencing — reuse work across projects.** Mention another project in your workspace and the agent can reuse its components, assets, and decisions instead of starting from scratch. It pulls a ranked, size-budgeted summary rather than dumping whole files, and every reference is logged so you can see what each project borrowed and from where. Read-only — referenced projects are never changed.

**Projects · Remix into any workspace \+ folder.** When you remix a project, choose exactly where the copy lands — which workspace and which folder — and it carries the original's name and details with a clear link back to the source.

## May 19

**Editor · Framework Lock \+ per-file lock.** Pin the framework choice for a project so regenerations can't drift it, and lock individual files so their contents survive every iteration. Both surface as toggles in the editor and workbench, on by default for new projects.

**Preview · Preview component refactor.** Device frame, resize, skeleton state, and web-component support all extracted into focused hooks. Keyboard-driven resize is accessible, reduced-motion is respected, and the cross-origin font noise from screenshot capture is silenced.

**Workbench · Header v11.3 — chip-style segmented control.** New animated chip control for device \+ view switching, keyboard shortcuts, a device dropdown, and a status text region so the workbench surface tells you what it's doing without you having to guess.

**Chat · Prompt queue: full audit \+ refactor.** Four-phase pass across the prompt queue — paste UI now reachable from an empty queue, double border in the chatbox fixed, and the surface as a whole moves from "works" to "feels deliberate."

**Templates · 14 starter templates repointed \+ SUP-SSR default.** Every starter template now flows through our own mirrors for supply-chain control. SUP-SSR (the TanStack Start scaffold with discoverability built in) is the recommended default; SolidJS is back in the catalogue.

**Brand · Editorial lineage as default brand.** New default brand voice draws on the longform editorial tradition — quiet typography, hairline rules, coral as the only signal color. Less SaaS-template, more masthead.
