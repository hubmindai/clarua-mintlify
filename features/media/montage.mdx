Montage plans and produces a video from a brief: script, scenes, and assembly handled as a pipeline with **quality gates between stages**, not a single risky one-shot.

## Built for real length

Montage is built for explainers and longer-form pieces where the steps need to hold together. Each stage checks its own output before the next one starts, so a bad script never runs through scene generation and rendering.

## Veo 3.1

The Montage video pipeline supports Google's **Veo 3.1** video models for scene generation.
