Maker studio turns plain-language descriptions into printable 3D models.

## What it produces

- Parametric 3D geometry ready to slice.
- Print-ready file exports.
- A working model to iterate on instead of a starting-from-zero CAD file.

## Where it fits

Good for hobbyist and functional parts described in ordinary language, without needing to model them by hand.
