Admins can set a monthly spending cap per workspace and override it for any individual. No surprise invoices, no manual policing.

## Per person, per month

- **Raise a power user** without lifting everyone.
- **Cap a contractor** to their engagement budget.
- **Freeze a member at zero** while still keeping them in the workspace.

Spend is metered per person in exact cents and resets cleanly at the start of each month.

## Enforced before the fact

- A **warning** the moment someone approaches their limit (default 80%).
- A **pre-flight check** that holds back work which would push them over.

Budgets are enforced before the spend happens, not reconciled after.

## What counts against a budget

| Activity | Metered |
| --- | --- |
| Agent turns | Yes, by model tier |
| [Background runs](/features/agent/background) | Yes, plus sandbox time |
| [Voice partner](/features/media/voice-partner) sessions | Yes, per minute |
| Preview and editor use | No |
| Publishing an app | No (fees are separate) |

## Buying credits

Members can purchase additional usage credits from Settings without leaving the app, and see their usage breakdown as percentages instead of raw numbers, so a member with a \$200 budget sees "you've used 62% this month" instead of a raw dollar figure that means nothing without context.

## Admin recipes

- **New contractor.** Set to a hard cap that matches the engagement, warning at 75%.
- **Growth engineer running experiments.** Higher cap, warning at 90%, no override.
- **Automation account.** Predictable monthly usage, capped just above expected.
