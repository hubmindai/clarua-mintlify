The command menu can search across all your workspaces, projects, and agents at once.

## Grouped by scope

Results are grouped by where they live and tagged with their scope. Switch the active scope to narrow things down, or search everything when you're not sure where a command lives.

## Single workspace

With a single workspace, nothing changes. It works exactly as before.
