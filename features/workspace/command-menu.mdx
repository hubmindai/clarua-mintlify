The command menu can search across all your workspaces, projects, and agents at once. Open it with `⌘K` (`Ctrl+K` on Windows and Linux).

## What you can search

- **Commands.** Every action you can take, from anywhere in the product.
- **Projects.** Recent, favorited, or any project you have access to.
- **Agents and sessions.** Jump straight into a conversation.
- **Skills and modes.** Trigger a [skill](/features/agent/skills) or switch a [custom mode](/features/agent/custom-modes).
- **Files.** Search across everything a project generated.
- **Docs and settings.** Deep-linked pages so you don't need to hunt.

## Grouped by scope

Results are grouped by where they live and tagged with their scope. Switch the active scope to narrow things down, or search everything when you're not sure where a command lives.

- **This project.** Only surfaces in the open project.
- **This workspace.** Everything in the current workspace.
- **All workspaces.** Anything you have access to.

## Single workspace

With a single workspace, nothing changes. It works exactly as before.

## Shortcuts worth learning

| Shortcut | Action |
| --- | --- |
| `⌘K` | Open command menu |
| `↑ ↓` | Move through results |
| `Enter` | Run the highlighted command |
| `⌘Enter` | Open in a new tab |
| `Esc` | Close |
