The Files surface holds every image, document, and asset a chat produced. No more digging back through messages.

## What you can do

- **Browse** every file the conversation generated.
- **Download** any of them.
- **Re-attach** a file to a later message.

## Chat attachments

Attached images are delivered to the model, the project, and the file library on the same turn. Anything you drop in ends up in one place you can find later.
