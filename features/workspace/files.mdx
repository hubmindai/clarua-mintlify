The Files surface holds every image, document, and asset a chat produced. No more digging back through messages to find the export from three turns ago.

## What you can do

- **Browse** every file the conversation generated.
- **Preview** in place: images, PDFs, CSVs, code files.
- **Download** any of them.
- **Re-attach** a file to a later message so the agent can use it again.
- **Rename or organize** into folders per project.
- **Share** with a signed link that respects your workspace policy.

## Chat attachments

Attached images are delivered to the model, the project, and the file library on the same turn. Anything you drop in ends up in one place you can find later.

Attachments work for:

- Images (screenshots, mockups, photos).
- PDFs and text documents.
- Spreadsheets (CSV, XLSX), also feeding [build from a spreadsheet](/features/build/from-spreadsheet).
- Code snippets and source files.

## Retention

- Files persist for the lifetime of the project by default.
- Deleted files stay recoverable inside the workspace's retention window.
- Signed share links can carry an expiry so they don't outlive their purpose.
