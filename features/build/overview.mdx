## Quality floor

Every generated app meets a production floor by default:

- Real page title, description, and meta.
- Alt text on images and labels on icon-only buttons.
- A single top-level heading and readable color contrast.
- Animations respect reduced-motion preferences.
- Form errors move focus to the first field to fix.
- Loading states for anything fetched lazily.

Clarua bakes this bar into how it generates apps, so the quality floor can't quietly regress between builds.

## Deterministic pipelines

Where the input has enough structure (a spreadsheet, a screenshot, an API spec, a design token file), the compile step runs deterministically. The same paste, image, or spec produces the same output every time, and you can hand-edit and recompile without surprises.
