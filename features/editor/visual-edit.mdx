Click an element in the live preview and edit it directly: text, spacing, color, layout. Changes are written straight back to the real source, not faked in the browser.

## How it stays honest

A deterministic bridge maps what you clicked to the exact line that produced it. Edits are precise and reversible, and the code stays the source of truth. Nothing about the visual editor bypasses the file system.
