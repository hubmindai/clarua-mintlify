The visual editor gives you real layout tools that write back to your source.

## Layout controls

Select any container, open the **Layout** section, and set:

- Flex direction.
- Alignment.
- Justification.
- Gap.
- Wrap.

Every choice compiles deterministically to conflict-resolved utility classes, so re-picking a direction cleanly replaces the old one, and turning on a layout makes the container flex in a single step.

## Spacing ruler and layers

- A **spacing ruler** shows margins, padding, gaps, and the distances between elements.
- A **layers tree** you can expand and collapse to follow nesting.

## Keyboard navigation

Arrow keys walk the structure: up to the parent, down into a child, left and right across siblings. Fast, mouse-free navigation.
