The visual editor gives you real layout tools that write back to your source. No CSS window, no separate stylesheet to keep in sync.

## Layout controls

Select any container, open the **Layout** section, and set:

| Control | What it does |
| --- | --- |
| Flex direction | Row, row-reverse, column, column-reverse |
| Alignment | Cross-axis alignment (start, center, end, stretch, baseline) |
| Justification | Main-axis distribution (start, center, end, between, around, evenly) |
| Gap | Space between children (single or split row and column) |
| Wrap | Whether children wrap to a new line |

Every choice compiles deterministically to conflict-resolved utility classes, so re-picking a direction cleanly replaces the old one, and turning on a layout makes the container flex in a single step.

## Spacing ruler

The spacing ruler overlays your selection with:

- **Margin** as an outer band.
- **Padding** as an inner band.
- **Gap** between children.
- **Distances** to neighboring elements.

Drag any band to adjust, or type an exact value. Hold Shift to scale symmetrically.

## Layers tree

The layers tree shows the component structure of the current page. Expand and collapse to follow nesting. Click a layer to select it; drag to reorder within its parent.

- **Hidden layers** are dimmed.
- **Component boundaries** are marked, so you can see where you leave one file and enter another.
- **Named layers** show their source name, so "Card / Header" reads as "CardHeader" in code.

## Keyboard navigation

- **Up arrow.** Move to parent.
- **Down arrow.** Move to first child.
- **Left / Right.** Previous / next sibling.
- **Enter.** Open the current element's inspector.
- **Escape.** Deselect.

Fast, mouse-free navigation for tuning nested layouts.
