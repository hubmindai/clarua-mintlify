Annotation mode lets you drop numbered pins on the live preview, each with a short note like "make this wider" or "wrong color here."

## Structured brief

The pins compile into a clean, numbered brief the builder reads on its next pass, so feedback lands on the exact elements you marked.

## Offline-safe

It's all plain structured data. It works offline, and it doesn't depend on a screenshot service.
