The Clarua agent isn't a single model call. It's a loop that plans, acts, and verifies against your project, with distinct modes, memory, and preferences. It can drive code, drive a browser, and drive a computer, and it can hand off work to itself in the background.

## The loop

Every turn runs the same shape, tuned by the current mode:

1. **Read.** Pull in the prompt, attachments, project rules, and any memory that applies.
2. **Plan.** State what will change, in files or on screen, before touching anything.
3. **Act.** Edit files, run tools, drive a browser, spawn sub-agents.
4. **Verify.** Auto-fix errors, run checks, re-read what was written.
5. **Record.** Save a receipt, update memory, notify anyone watching.

The loop stops when the goal is reached, the budget is spent, or a gate you set (plan approval, safety check) holds it.

## Choosing how much control

- **Plan mode on, auto-approve off.** You see and approve every plan. Best for unfamiliar codebases and risky work.
- **Plan mode on, auto-approve on.** Plans still generate, but they run. Best for daily work you trust.
- **Plan mode off.** The agent goes straight from prompt to action. Best paired with a tight [custom mode](/features/agent/custom-modes) and [checkpoints](/features/editor/checkpoints).
