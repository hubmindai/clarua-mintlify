The prompt queue is manageable, not a one-shot commitment.

## What you can do to a queued item

- **Hold** it so it doesn't run yet.
- **Reorder** it against other items in the queue.
- **Edit** its text before it runs.
- **Copy** it to start a new item from the same prompt.
- **Repeat** it after it's run.

## Activity side panel

A ChatGPT-style turn activity view shows what the agent did on the current turn, in a side panel you can open or dismiss. See the work as it happens instead of scrolling the transcript.
